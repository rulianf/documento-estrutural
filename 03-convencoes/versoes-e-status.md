# Versões e status dos documentos

| Status do documento | Significado |
| --- | --- |
| Rascunho | Em escrita; pode ter lacunas marcadas |
| Em revisão | Aguardando revisão ou validação |
| Aprovado | Vigente; só muda por registro de alteração |
| Substituído | Trocado por versão nova; guardado no histórico |

## Numeração

Use versão **0.x** para rascunho, **1.0** quando aprovado, **1.1, 1.2** para ajustes pequenos e **2.0** quando o escopo muda.

## Histórico

Todo documento aprovado ganha, no fim, uma tabela de histórico:

| Data | Versão | O que mudou | Quem aprovou |
| --- | --- | --- | --- |
| | | | |

Quando uma decisão muda durante a construção, a especificação ou o desenho é atualizado **antes** de a tarefa ser dada como pronta.

No Git, cada documento aprovado pode receber uma tag ou um commit com a versão no texto da mensagem, e as versões substituídas vão para a pasta `99-Historico` do cliente (veja [pastas por cliente](pastas-por-cliente.md)).
