# Fase 5 — Validação e aceite

| Item | Conteúdo |
| --- | --- |
| Objetivo | Comprovar que a solução faz o que foi especificado e obter o aceite do cliente |
| Responsável | Breno executa os testes; Rulian revisa os resultados; Lucas conduz a validação com o cliente; o cliente aceita |
| Entradas | Solução construída, [Plano de testes](../02-templates/fase-3-desenho-tecnico/plano-de-testes.md) e critérios de aceite da Especificação |
| Atividades | Executar os casos de teste de cada requisito; registrar evidências e defeitos; corrigir e testar de novo; validar com o cliente usando dados reais ou uma amostra combinada; medir contra a linha de base quando já for possível; registrar o aceite, com as restrições e pendências aceitas |
| Documentos | [Relatório de testes](../02-templates/fase-5-validacao/relatorio-de-testes.md); [Registro de entrega e aceite](../02-templates/fase-5-validacao/registro-de-entrega-e-aceite.md) |
| Portão | Cliente aceitou conforme os critérios; nenhum defeito crítico aberto; pendências aceitas estão registradas |
| Erros comuns | Aceite só de palavra, sem registro; testar apenas o caminho feliz; ignorar as exceções da especificação; validar com dados fictícios que escondem problemas reais; corrigir defeito sem testar de novo |
| Papel da IA | Gerar casos de teste a partir dos critérios de aceite, apontar requisitos sem teste e resumir resultados. Resultado e aceite são decisões humanas |

Fase anterior: [construção](fase-4-construcao.md). Próxima fase: [implantação e operação](fase-6-implantacao-e-operacao.md).
